Agent governance

Guardrails for AI coding agents

Three open source npm packages, and a review gate for an AI agent fleet at work. In my experiment, where a rule lived only in a decision record, agents asked to purge old orders hard-deleted them in 4 of 4 runs without it and kept the order numbers in 3 of 3 with it.

Goal: Get the speed of AI coding agents on production codebases without losing control of what they change.

One package for each point where an agent's work can go wrong. agent-contract blocks any write outside the task's scope before it lands. repo-memory keeps the reasons behind the code as records that CI checks and only a human can accept. change-evidence reads every pull request as data and tells the reviewer where to look. I build Lawyering under all three. At SeamlessHR I built the review gate between our engineers and the company's AI agent fleet.
