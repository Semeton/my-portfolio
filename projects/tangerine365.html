Tangerine365

One multi-tenant LMS for banks and enterprises, replacing a separate codebase per client.

Technical lead and solutions architect, Zercom Systems · 2023 – 2024 · tangerine365.com ↗

Business goal

Sell one learning platform to banks and enterprises with very different branding, compliance and infrastructure rules, without maintaining a copy of the code for every client.

Context

  • –A Central Bank of Nigeria-mandated vulnerability scan flagged the LMS's PHP 7.4 runtime as end-of-life. The banks' remediation deadline became ours.
  • –Each client ran its own hand-edited copy of the project. Ten clients meant ten diverging codebases, so a bug fix shipped ten times.
  • –Days before one bank's go-live, its infrastructure team required SQL Server. The previous vendor had abandoned a separate SQL Server fork because it couldn't keep two repositories in sync.

Decisions

Shrink to a core, then rebuild upward

Strip the LMS to a lean core on PHP 8.1, then re-add modules one at a time as plugins, so each bank turns on only the features it bought.

One codebase, two database drivers

MySQL by default and SQL Server where a bank requires it, chosen at runtime by a dispatcher. Every query is written twice, which is the cost of never forking again.

Tenancy by subdomain or by ID

Tenants are separated by subdomain by default (tenant.tangerine365.com). Inside Human Manager HRMS they are scoped by ID, so every new HRMS customer gets an LMS automatically. Branding is configuration, not code.

Deploy from release tags, not zip files

Bank deployments moved from operators copying zip files to git pulls of verified release tags during controlled windows. That gave the banks an audit trail, integrity checks and rollback.

Size and design each deployment

I wrote the infrastructure sizing and deployment architecture for each client. First Bank's on-premise build runs external load balancer → two proxying web servers → internal load balancer → two app servers → central SQL Server.

Result

  • –One codebase deployed at Wema Bank, First Bank, PremiumTrust Bank and Seven-Up Bottling Company, plus a self-serve cloud product.
  • –Over 10,000 production users, most migrated from the legacy LMS.
  • –Production then taught the rest: queue-backed reports, an in-app scheduler, chunked proctoring recordings and mandatory authenticator-app 2FA for admins.
