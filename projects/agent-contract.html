Agent Contract

Deterministic guardrails for AI coding agents, published on npm.

Creator · 2026 – present · agent-contract.semeton.xyz ↗

Business goal

Get the speed of AI coding agents on production codebases without turning every review into an audit of what else the agent touched.

Context

  • –Agents drift beyond the task: renaming functions, refactoring unrelated modules.
  • –Instruction files like CLAUDE.md communicate intent but don't enforce it.

Decisions

Move determinism out of the model

The repository declares roles, each with a path scope. Every write an agent attempts is checked against the contract before it happens, and writes outside scope are blocked.

Memory lives in the repo

Decisions, conventions and a codebase map persist between sessions instead of being rediscovered, which also cuts context use.

Provider-independent

The same contract holds for Claude, Codex or Copilot.

Result

  • –Review shifts from 'what else did it touch?' to 'is this the right solution?'.
  • –Shipped as npm i -g @semeton/agent-contract, with a companion Azure Boards CLI. I use it daily, including on this site.
