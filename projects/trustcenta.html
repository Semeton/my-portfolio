TrustCenta

A multi-tenant security platform: vulnerability scanning, risk, compliance, staff training and phishing simulation in one product.

Sole engineer · 2024 – present · trustcenta.com ↗

Business goal

Give a company one place to find its security weaknesses, track the risk, prove compliance and train its staff, instead of a separate tool for each.

Context

  • –Five disciplines in one product, built on three open-source engines: OWASP ZAP for scanning, Gophish for phishing simulation and CISO Assistant for compliance frameworks.
  • –Each engine brings its own runtime and database, and none of them knows about tenants.
  • –In 2026 the production server was found running a cryptominer. Small convenience decisions had added up: a web-panel user in the docker group, one flat Docker network, root processes in containers, admin panels on the public internet.

Decisions

Own the domain, wrap the engines

ZAP, Gophish and CISO Assistant each sit behind an adapter. TrustCenta owns the data model, and replacing an engine means rewriting one adapter.

Long scans run on a queue

A scan can take more than 30 minutes, so the API queues it and returns at once. A worker drives ZAP with timeouts and retries, and reports the real reason when a scan fails.

Connect the domains through events

A finished scan turns high and critical findings into risks and files the report as compliance evidence. A failed phishing test assigns the employee training. A workflow engine handles these links, so modules never import each other.

One database, company-scoped queries

Every domain table carries a company ID taken from the signed-in session. One database means one migration path and one backup. The cost is that a missing filter would leak data, so the architecture review names database row-level security as the next safeguard.

Wipe, don't patch; then expose nothing

After the compromise I treated the host as untrusted, reinstalled it and rotated every credential. The services still share one Docker network, but none of them publishes a port, and the whole server sits behind a firewall.

Result

  • –One product covering five security disciplines, including an ISO 27001 Statement of Applicability and a reviewed mapping from Cyber Essentials to ISO 27001.
  • –A public post-mortem on what convenience cost, and the architecture it should have had on day one.
